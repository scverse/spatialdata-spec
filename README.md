# SpatialData specifications: Python in-memory format

This branch holds the Python in-memory format of the [SpatialData](https://github.com/scverse/spatialdata)
specification: how the Python implementation, `spatialdata`, represents a dataset in memory. It
describes `spatialdata` 0.8 and represents version 1.0 of the abstract data model, which is on the
branch `data-model`: each part of the in-memory format follows the part of the data model it
represents, included from there when the website (branch `site`) builds the pages.

- [`in-memory-python.md`](in-memory-python.md): the Python in-memory format
- [`in-memory-python-guide.md`](in-memory-python-guide.md): implementation guide (not normative)

How to contribute is in [`.github/CONTRIBUTING.md`](.github/CONTRIBUTING.md).

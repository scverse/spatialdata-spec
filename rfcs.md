# RFCs

RFCs (requests for comments) are written proposals for large features or big breaking changes of
the SpatialData data model, the storage format, or several in-memory formats at once. When to write
one and the process are in {ref}`contributing-rfcs`; new RFCs start from the
{doc}`RFC template <rfcs/template>`.

% the table is written by build.py from the headers of the files in rfcs/
% begin rfc-table
% end rfc-table

Type: what the RFC changes, one or both of *data model* · *storage format*; *discussion* when it changes
neither, e.g. an RFC about implementations.

Statuses: *planned* (agreed to be written) · *idea* (not yet written up) · *draft* ·
*under review* · *accepted* · *rejected* · *withdrawn* · *implemented*.

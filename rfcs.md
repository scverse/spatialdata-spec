# RFCs

RFCs (requests for comments) are written proposals for large features or big breaking changes of
the SpatialData data model, the storage format, or several in-memory formats at once. When to write
one, the process and a template are in {ref}`contributing-rfcs`.

% the table is written by build.py from the headers of the files in rfcs/
% begin rfc-table
% end rfc-table

Targets: the data model and storage format versions an RFC changes, as stated in its header; for
RFCs not yet written, the proposed targets.

Statuses: *planned* (agreed to be written) · *idea* (a discussion, not yet written up) · *draft* ·
*under review* · *accepted* · *rejected* · *withdrawn* · *implemented*.

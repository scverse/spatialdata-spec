# RFCs

RFCs (requests for comments) are written proposals for large features or big breaking changes of
the SpatialData data model, the storage format, or several in-memory formats at once. When to write
one and the process are in {ref}`the RFC section of the contributing guide <contributing-rfcs>`;
new RFCs start from the {doc}`RFC template <rfcs/template>`.

% the table is written by build.py from the headers of the files in rfcs/
% begin rfc-table
% end rfc-table

Type: what the RFC changes, one or both of *data model* · *storage format*; *discussion* when it changes
neither, e.g. an RFC about implementations.

Statuses: *idea* (not yet written up) · *planned* (agreed to be written) · *draft* (pull request
open) · *under review* (on this page, discussed and revised) · *accepted* (design agreed) ·
*specified* (in the draft of the next version) · *released* (in a released version) · *rejected* ·
*withdrawn* (by its authors); the process, with a figure, is in
{ref}`the contributing guide <contributing-rfcs>`.
